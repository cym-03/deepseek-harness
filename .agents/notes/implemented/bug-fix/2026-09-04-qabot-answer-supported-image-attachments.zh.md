# Agent Note: 附加 Qabot 回答点名的图片

Status: implemented

[English](2026-09-04-qabot-answer-supported-image-attachments.md) | 中文

## Problem

视觉检索只对员工问题评分。文本检索生成的回答可能识别出带说明的图片，但视觉查询只选中相关画板，导致消息正文点名了图片，附件列表却没有展示。

## Decision

Qabot 保留基于问题的视觉向量检索，并把图片说明或画板标题明确出现在回答中的有效资产排在结果前面。自动结果可以来自任意活跃知识源，但素材标题必须与问题或回答共享具体的非通用主题词。自动结果还要求单个结果达到 `0.45`，或两个有图片说明的结果都达到 `0.40` 且分数差不超过 `0.02`；回答明确点名的图片不受这些阈值限制。确定性合并复用已有资产记录和查询向量，按资产 ID 去重，保留正文中的提及顺序，并遵守配置的结果数量上限。

通用文档图片标签不算明确提及，因为一个被引用的文档标题可能对应多张没有说明的图片。助手正文只用于选择已经建立索引的资产，不会触发第二次向量请求。

## Alternatives considered

- **对完整回答再次生成向量：** 拒绝，因为每个不同回答都会额外消耗一次视觉查询额度，并产生低价值缓存。
- **降低全局视觉相似度阈值：** 拒绝，因为同一本员工手册中的无关图片会出现在普通问题下。
- **只使用原始问题：** 拒绝，因为文本检索可能识别出问题没有直接点名的精确图片说明。

## Consequences

回答点名带说明的图片时，该图片会显示在高置信的纯向量匹配之前。只通过“申请”“审批”“流程”等通用词重叠的流程图、弱相关资产和没有具体说明的通用图片仍被排除，来自其他知识源的真正相关图片可以继续展示。每个员工问题最多仍只执行原有的缓存视觉查询，或在缓存缺失时调用一次视觉向量模型。

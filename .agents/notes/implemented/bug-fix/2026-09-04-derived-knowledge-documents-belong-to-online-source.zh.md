# Agent Note: 派生知识文档归属于提交的在线知识源

Status: implemented

[English](2026-09-04-derived-knowledge-documents-belong-to-online-source.md) | 中文

## Problem

画板 OCR 会生成可检索文本，其稳定键会在已提交的飞书知识源键后追加 `:board-text:<token>`。MySQL 投影将这些文档视为独立知识源，导致知识源页面和五分钟定时任务展示并同步没有提交人身份的内部 OCR 记录；移除已提交文档后，其派生文字还可能继续参与检索。

## Decision

MySQL 投影将画板文字、文档图片和视觉资产统一映射到[在线知识源生命周期](../architecture/2026-09-02-qabot-online-knowledge-sources.md)使用的已提交来源键。迁移会把现有画板文字文档移到父知识源，并软移除意外生成的来源记录。如果父知识源已经包含相同文档键，迁移后的重复项会使用无冲突的历史键并保持离线。

迁移只修改归属元数据。现有知识块、资产和向量继续关联原文档版本，因此清理过程不会调用嵌入或视觉模型。

## Alternatives considered

**只在知识源页面隐藏派生记录。** 拒绝，因为定时同步、检索过滤和知识源移除仍会把它们当成独立来源。

**删除派生文档并重新生成。** 拒绝，因为这会丢弃有效的 OCR 文字和向量，并浪费模型额度重建未变化的数据。

**将每个画板作为在线知识源管理。** 拒绝，因为画板继承已提交文档的访问、同步和移除生命周期，没有独立提交人或链接。

## Consequences

知识源配置只包含提交的在线文档，每次定时同步覆盖该文档派生的全部文字和媒体。移除知识源时，其画板 OCR 内容也会随其停止召回。历史错误来源会软移除以便追溯，其中仍可用的文档和向量归属于活动父来源。
